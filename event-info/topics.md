# Interesting Topics at AWS re:Invent 2025

AWS re:Invent features hundreds of sessions across cloud computing themes. Below is a comprehensive list of anticipated topics and example sessions (based on trends from previous years). These cover emerging technologies, best practices, and innovations. Sessions are typically rated by level (100-400, from introductory to expert).

## AI and Machine Learning
- Generative AI integrations with Amazon Bedrock and SageMaker
- Building custom ML models for enterprise (e.g., fraud detection, personalization)
- AI ethics and responsible AI frameworks
- Example Sessions: "Scaling GenAI Workloads on AWS," "Amazon Q for Business Automation," "ML Ops Best Practices"

## Compute and Serverless
- Advances in EC2, Lambda, and Fargate
- Serverless architectures for high-scale applications
- Graviton processors for cost optimization
- Example Sessions: "What's New in AWS Lambda," "Building Event-Driven Apps with EventBridge," "Optimizing Compute for Sustainability"

## Databases and Analytics
- Amazon RDS enhancements and Aurora innovations
- Big data analytics with EMR and Athena
- Real-time data streaming with Kinesis and MSK
- Example Sessions: "Migrating to Amazon Aurora," "Analytics at Scale with Redshift," "Graph Databases with Neptune"

## Security and Compliance
- Zero Trust architectures and IAM best practices
- Ransomware protection and data encryption
- Compliance in regulated industries (e.g., healthcare, finance)
- Example Sessions: "AWS Security Hub Deep Dive," "Implementing Zero Trust with Nitro Enclaves," "GDPR and CCPA Compliance Strategies"

## Networking and Edge
- Global network optimizations with Global Accelerator
- Edge computing with Outposts and Local Zones
- 5G and IoT integrations
- Example Sessions: "Hybrid Cloud Networking," "Edge AI with Snow Family," "Secure VPC Architectures"

## Storage and Backup
- S3 innovations for intelligent tiering
- EBS and EFS performance tuning
- Disaster recovery with AWS Backup
- Example Sessions: "Cost-Effective Storage Strategies," "Multi-Region Replication," "Archival with Glacier"

## Developer Tools and DevOps
- CI/CD pipelines with CodePipeline and CodeBuild
- GitHub integrations and developer productivity
- Infrastructure as Code with CDK and Terraform
- Example Sessions: "Automating Deployments with AWS SAM," "Observability with CloudWatch," "Shift-Left Security in DevOps"

## Industry-Specific Topics
- Cloud for Healthcare (e.g., HIPAA-compliant architectures)
- Financial Services (e.g., blockchain and fintech)
- Media & Entertainment (e.g., content delivery with MediaLive)
- Example Sessions: "AWS for Startups," "Sustainability in Manufacturing," "Gaming Innovations with GameLift"

## Emerging and Future-Focused Topics
- Quantum computing with Amazon Braket
- Sustainable cloud practices (e.g., carbon footprint reduction)
- Web3 and decentralized apps
- Space and satellite data processing with Ground Station
- Example Sessions: "Quantum Computing Primer," "Green Cloud Initiatives," "Metaverse Building on AWS"
