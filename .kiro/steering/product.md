# Product Overview

This repository contains demo projects, code samples, and resources for AWS re:Invent 2025. The project showcases various AWS services, architectures, and best practices for the annual AWS cloud computing conference held in Las Vegas, Nevada (November 30 - December 4, 2025).

## Purpose

- Demonstrate AWS service integrations and architectures
- Provide reference implementations for conference attendees
- Share best practices for cloud computing patterns
- Support presentations and workshops at re:Invent 2025

## Key Focus Areas

- AI/ML integrations (Bedrock, SageMaker)
- Serverless architectures (Lambda, EventBridge)
- Security and compliance patterns
- Edge computing and networking
- DevOps and infrastructure as code
